# La búsqueda de Vale — demostración

Este proyecto publica únicamente la demostración de presentación.

- **Cables y generadores:** comienza directamente en la sala de energía, con tres pilas de repuesto y tres fusibles. Tras encender los tres generadores, sintoniza el receptor señalizado abajo a la izquierda, en esa misma sala. Completa la prueba del flash y sal por abajo a la derecha. Si se agota la cámara durante la prueba, T recarga un flash junto al receptor.
- **Persecución:** pulsa E una vez ante cada uno de los dos generadores. Al encender ambos, la salida superior izquierda se abre inmediatamente: acércate y pulsa E. Armarios cerrados, una estatua y cajas forman obstáculos pequeños con espacio para rodearlos. La entidad comienza cerca de la salida y tiene velocidad moderada, con aceleraciones anunciadas. Mayús permite correr y G usar el flash. Las tres pilas se comparten entre cámara y linterna.

WASD/flechas para caminar, Mayús para correr, E para interactuar, Q para equipo, F para linterna, R para pila, C para visor, G para flash, T para pila de cámara y P para pantalla completa.

Los guardados de esta demo son independientes de los del juego completo.
El juego completo de diez episodios se conserva por separado y no se publica en esta edición.

Sin compilación ni dependencias: Vercel sirve `index.html` desde la raíz.
Las antiguas direcciones del HTML redirigen al menú de la demo.
