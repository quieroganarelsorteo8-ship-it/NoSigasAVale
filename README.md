# La búsqueda de Vale

Juego completo de diez episodios. Desde el menú se puede iniciar una partida, continuar o elegir un episodio. El progreso y el vestuario se guardan en el navegador.

Usá WASD o las flechas para caminar, Mayús para correr, E para interactuar y Esc para pausar. La tienda se abre desde la pausa y usa monedas de pago simulado.
